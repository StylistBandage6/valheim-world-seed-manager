## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Seed Library** | Save and rate Valheim world seeds with biome and spawn notes |
| **Metal Notes** | Log ore deposit locations per seed for efficient resource gathering |
| **Spawn Quality** | Rate starting spawn areas by biome access and nearby resources |
| **Seed Share** | Export seed notes as shareable summaries for the community |
